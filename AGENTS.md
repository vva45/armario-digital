# Guía de trabajo

- La interfaz y los mensajes visibles se escriben en español.
- Mantén separadas presentación (`app/`, `components/`), dominio (`domain/`) y persistencia futura.
- `Trabajo`, `Salir`, `Casa` y `Dormir` son usos; `Conjuntos` es una sección.
- No incluyas secretos, fotografías personales, datos inventados ni éxitos simulados.
- No conectes proveedores, despliegues ni servicios de pago sin autorización explícita.

## Comandos

- `npm install`: instalar dependencias y generar el lockfile.
- `npm run dev`: desarrollo.
- `npm run typecheck`: tipos.
- `npm run lint`: lint.
- `npm test`: pruebas unitarias y accesos.
- `npm run build && npm start`: build y servidor de producción.
